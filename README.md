# AI Self Research

Archive repository for experiments run by the **AI Perpetual Lab** — a
Karpathy-style autonomous, goal-directed iteration loop running on the Oracle
ARM box.

Every experiment is archived as a folder `YYYY-MM-DD_HHMMSS_slug/` containing:

- `README.md` — summary
- `log.txt` — full iteration log
- `solution.txt` — final solution
- `metadata.json` — structured metadata

Each experiment is committed and pushed here automatically when the lab
finishes a problem.
