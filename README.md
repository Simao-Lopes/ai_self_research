# 🧪 AI Self Research

Repositório de experiências do **AI Perpetual Lab** — um loop autónomo de investigação baseado no [autoresearch](https://github.com/karpathy/autoresearch) do **Andrej Karpathy**.

Cada pasta contém o resultado final de um problema explorado, incluindo o log completo de iterações, a solução final e documentação.

## 📂 Estrutura

```
YYYY-MM-DD_HHMMSS_descricao-do-problema/
├── README.md       → Explicação do problema e contexto
├── log.txt         → Registo completo das iterações
├── solution.txt    → Última solução gerada
└── metadata.json   → Metadados (datas, iterações, etc.)
```

> Gerado automaticamente via [AI Perpetual Lab](https://github.com/Simao-Lopes/web_games/blob/main/README.md)
